# Speech Processing Coursework

A collection of coursework and experiments in **speech processing, DSP, and machine learning for audio**.

## Topics

Materials and assignments cover:

- speech and language fundamentals;
- digital signal processing;
- probability for speech systems;
- signal representations;
- neural networks;
- CNNs, RNNs, attention, and Transformers;
- audio filtering and Fourier-domain analysis;
- speech datasets and recognition-oriented exercises.

## Practical work

The homework folders include Python/Jupyter implementations, audio recordings, reports, and experiments such as:

- DTFT/filtering utilities;
- windowing and spectral analysis;
- speech/audio preprocessing;
- notebook-based ML exercises;
- small speech datasets used for assignments.
